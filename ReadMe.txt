A Java Login and Registration System

This is a simple console-based Java application that allows users to register and log in with a username, password, and cell phone number. The system validates input according to specific formatting and complexity requirements, and includes JUnit unit tests to ensure proper functionality.


This is how it works:
- Register a new user
- Validate username (must contain underscore and max 5 characters)
- Validate password complexity (min 8 characters, includes uppercase, number, special character)
- Validate South African cell phone format (e.g., +27831234567)
- Login functionality
- Unit tests with JUnit 5
